## ⚖️ About

A responsive web application promoting gender equality in alignment with the United Nations Sustainable Development Goal 5 (SDG 5). Developed collaboratively in a 4-member team, the project focuses on raising awareness through an accessible and visually engaging UI built entirely with frontend web technologies.

---

## ✨ Features

- 🌍 **SDG 5 Awareness** — Educates and promotes gender equality through interactive content
- 📱 **Responsive UI** — Fully responsive layout that adapts across all screen sizes
- 🎨 **Clean Design** — Accessible and visually engaging frontend interface
- 🤝 **Team Collaboration** — Developed in a 4-member agile team with shared responsibilities
- ⚡ **Pure Frontend** — Built entirely with HTML5, CSS3, and JavaScript — no frameworks
