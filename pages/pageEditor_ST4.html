Sitemap

Technical Description

I use "display: flex;", "justify-content: center;", "align-items: center;", and "height: 100vh;" to center my sitemap both vertically and horizontally within the veiwport(100vh height).

And "pointer-events: all;" applied to the ellipsed and text in the sitemap enables them to respond to mouse events like click and hover.

And "text-anchor: middle;" and "dominant-baseline: middle;" help position the text inside the sitemap ellipses. Horizontally centering the text and vertically aligning the text to the middle respectively

And I use "fill", "stroke" and "stroke-width" properties to style the sitemap as I desire.

At the beginning of the sitemap I use 'viewBox="-10 -10 1187 564"', 'preserveAspectRatio="xMidYMid meet"', 'fill="none"' and 'xmlns="http://www.w3.org/2000/svg"'. They define how the sitemap elements must behave once rendered. They define the coordinate system and dimensions of the SVG canvas, how the SVG should scale when it’s resized, the fill color of the SVG shapes and declares the XML namespace for the SVG respectively.

The ellipses create the nodes of the sitemap and the lines create the connections between the nodes.

Accessibility

I addressed accessibility in this page by allowing keyboard navigation between the nodes in addition to interaction capability with the mouse. I also added tootips and alternate text to facilitate screen readers.

User Profile Page

Technical Description

I created separate div containers for the different cards in the user profile.

And for the calendar I employed a colour based scheme to identify whether the user is available on a specific day or not. I created the calndar using the HTML table element. Then I emploed hover effects to discern availability or unavailability (also supported by tooltips). On days she is not available, the particular tile of the day turns red on hover. On days she is available, the tile turns green on hover, and then changes colour according to the time of day she is available. To achieve such smooth transitions from one colour to another is used 'transition: background-color 0.9s ease-in-out 3s;' and 'animation: availabilityHover 0.9s forwards;'. I then set up a colour legend system to help the colour identification.

Accessibility

I implemented accessibility in this page by adding alternate text for the images and tooltips.

Content Page

Technical Description

I added a hero section to my content page. It acts as a simple splash screen to my content page.

I added a button in the hero section saying "Learn More" that when pressed takes you to the content of the page.

I also added a "position: fixed" navigation bar to my content page so users can navigate between the different sections of my content.

I also added a To Top button that stays on screen at all times. Also "position: fixed", so users can simply click if they want to go to the top rather than tirelessly scroll. I used effects like "transform: translateX(-50%);" and "background: rgba(0, 0, 0, 0.2);" to make the navigation bar look nice.

Accessibility

I used alternate text for my page for accessibility.

Challenges and Lessons Learned

One of the challenges I faced with my user profile page is absolute positoning. Relative positioning and responsive structuring makes website manipulation easier. I overcame the challenge of this by adjusting the positioning values of the page elements but this is not reccomended for large websites.

Compliance

My pages comply to janet regulations because images include alternate text for accessibility; I have used aria labels in my sitemap, I have included keyboard navigation for my sitemap; and I have used semantic HTML elements; the colours used provide good contrast for visibility; I have used form labels(label for = "name"); and I have used focus indicators for keyboard navigation (tabindex=0;).
