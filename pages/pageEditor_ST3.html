Feedback Form

Technical Description

  • HTML Form Elements: input, textarea, select, fieldset and legend tags are used in html forms and also added a feature where some fields are required attributes.
  • JavaScript Form Validation: Regex-based validation with real-time error messages.
  • Character Counter: Dynamic update for textarea with a 500-character limit.
  • Interactive Elements: Radio buttons, checkboxes, dropdowns, and file uploads.
  • CSS Styling: border-radius, box-shadow, and hover effects for better UX.
  • Keyboard Handling: Prevents accidental submission via Enter ke

Assessibilty

  • Semantic HTML: fieldset and legend for screen readers.
  • High Contrast and Readability: Dark text on light backgrounds with focus styling.
  • Keyboard Navigation: Fully accessible without a mouse.
  • Error Messaging & Feedback: Clear red error messages and input highlighting.

Team Page

Technical Description

  • CSS Flexbox Layout – Used display: flex in .team-avatars to align team members' avatars responsively.
  • Dropdown Interaction – Hover effect makes the .dropdown content visible using opacity and visibility transitions.
  • Avatar Hover Effects – transform: scale(1.03) and border: 2px solid #ff5733 applied on hover for an interactive effect.
  • Custom Button Styling – .avatar-button is styled with background: none and border: none for a clean, image-only clickable button and this button feature helps to navigate through the page by keyboard
  • Smooth Transitions – Applied transition: opacity 0.4s ease-in-out, transform 0.4s ease-in-out; for dropdown animation.

Accessibility

  • Keyboard Navigation Support – avatar-button:focus allows users to navigate using the keyboard.
  • Color Contrast for Readability – White text on a dark background ensures clarity (color: white; for dropdown text).
  • Semantic HTML Elements – Used button, ul, li, and p tags correctly to structure content in an accessible way.
  • Alt Attributes on Images – Each avatar image has a meaningful alt description for screen reader users (incase the images doesnt load etc).

Content Page

Technical Description

  • Hero Section with Background Image – Applied background-image: linear-gradient(...) for an overlay effect on the hero section.
  • Fixed Side Navigation Menu – Used position: fixed; top: 75%; left: 20px; to keep navigation accessible throughout scrolling.
  • Responsive Flexbox Layout – Utilized display: flex; flex-wrap: wrap; in .content for adaptability on various screen sizes.
  • Go-to-Top Button – Positioned position: fixed; bottom: 20px; right: 20px; for quick navigation to the top
  • Hover Effects for Links & Buttons – Applied transition: background 0.3s; for a smooth color change on interaction.

Accessibility

  • High Contrast Colors – Used gold (#FFD700) and red (#E74C3C) for text to enhance readability.
  • Keyboard Navigation Support – Side navigation and buttons are accessible with keyboard tab and enter keys.
  • Descriptive Alt Text for Images – Ensures assistive technologies can describe images to users.
