Splash Page

Technical Description

The splash screen uses HTML and CSS to create a visually engaging introduction before redirecting to the homepage. The meta refresh tag (`http-equiv="refresh"`) automatically navigates users to `home.html` after 4 seconds. A centered container (`.splash-container`) holds the title, mission statement, team credit, and a CSS-animated loader (`.loader`) to enhance user experience. Flexbox or absolute positioning ensures proper alignment, while CSS animations add a smooth loading effect. This design provides a seamless transition to the main website while reinforcing the theme of gender equality.

Accessibility

The splash screen enhances accessibility by using semantic HTML for screen reader compatibility, ensuring proper content hierarchy with headings and paragraphs. High contrast text and readable fonts improve visibility, while the loading message informs users about the redirection process. Although the page auto-redirects, the clear structure ensures assistive technologies can interpret the content effectively. These considerations create an inclusive experience for all users.

Volunteer Page

Technical Description

The Volunteer Page uses HTML5 and CSS to create a structured and visually appealing layout. Semantic tags like `header`, `section`, and `footer` enhance readability and accessibility. A navigation bar (`nav`) provides easy page transitions, while a card-based layout (`div class="card"`) presents volunteer opportunities with images, headings, descriptions, and buttons. Styling is handled via an external CSS file (`volunteer.css`), ensuring separation of content and design. Flexbox or Grid is used for layout alignment, making the page responsive. Key design elements include box shadows, border-radius, and padding for a modern look. Media queries enhance mobile compatibility, ensuring a seamless user experience.

Accessibility

The Volunteer Page ensures accessibility by using semantic HTML elements like `header`, `section`, and `footer` for clear structure. Alt text for images improves accessibility for visually impaired users, and descriptive buttons ensure screen readers can identify their function. High-contrast text enhances readability for users with visual impairments, making the page more inclusive.

Content Page

Technical Description

The Content Page utilizes semantic HTML elements like `header`, `section`, and `footer` to establish a clear, accessible structure. The navigation menu is implemented with an unordered list (`ul`), which aids in organizing links and enhancing accessibility. Images are accompanied by alt text to improve accessibility for visually impaired users. CSS is used to style the layout with properties like flexbox or grid for responsive design, ensuring the page adjusts across different screen sizes. The use of box shadows, padding, and borders adds a modern, visually appealing touch, while media queries ensure the design remains mobile-friendly. These choices create a functional, accessible, and visually engaging page.

Accessibility

To address accessibility on the Content Page, semantic HTML elements like `header`, `section`, and `footer` were used to create a logical structure that aids screen readers. Alt text for images ensures content is accessible to visually impaired users. The navigation menu is built with an unordered list (`ul`) for better screen reader interpretation, and high-contrast text improves readability. Additionally, buttons with clear labels ensure accessibility for users relying on assistive technologies, providing an inclusive experience for all users.

Challenges and Lessons Learned

The main challenges encountered were ensuring responsive design across devices and accessibility for users with disabilities. Initially, some elements did not align properly on smaller screens, which was resolved with media queries. Accessibility issues were addressed by adding alt text for images and ensuring buttons were screen-reader friendly. Additionally, managing the auto-redirect on the splash screen required clear loading messages to avoid confusion. The key lesson learned was the importance of thorough testing to ensure the page works smoothly across devices, browsers, and for all users.

Compliance

The pages created follow general accessibility guidelines such as using semantic HTML, adding alt text to images, and ensuring high-contrast text for better readability, in line with WCAG standards. They do not collect personal data, aligning with basic GDPR principles. While these pages meet basic accessibility and privacy requirements, further steps would be needed for full Janet compliance, especially regarding data handling and privacy policies.
